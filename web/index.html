Android Studio · ADB로 연결

  1. 준비 (처음 한 번) 내 PC에 adb(Android SDK Platform-Tools)와 Marionette CLI(marionette)를 설치하고 PATH에서 실행되는지 확인하세요.
  2. 개인 토큰 설정 상단 API / MCP에서 발급한 개인 토큰을 터미널에 MARIONETTE_TOKEN 환경 변수로 설정하세요. 토큰이 없으면 아래 명령이 실패해요. read -r MARIONETTE_TOKEN; export MARIONETTE_TOKEN
  3. 연결 코드 만들고 실행 코드는 90초 안에 한 번만 쓸 수 있어요. 만료되면 새 코드를 만드세요.

에이전트 연결

휴대폰이나 에뮬레이터를 운영할 PC를 연결합니다.

  1. 1

    에이전트 ID와 이름 정하기

    PC마다 ID가 달라야 해요. 영문, 숫자, - 와 _ 만 쓸 수 있어요.

  2. 2

    대상 PC에서 명령 실행하기

    ID를 등록하면 대상 PC에서 실행할 명령이 여기에 표시돼요.

    Ubuntu PC의 터미널에 붙여넣으세요. curl이 필요하며 sudo가 필요한 작업은 실행 전에 확인을 요청해요.

    macOS 또는 Linux에서 패키지를 풀고 adb를 준비한 뒤 패키지 폴더에서 실행하세요. 에뮬레이터를 쓰려면 Android SDK와 JDK도 필요해요.

    항상 켜 두려면 같은 값을 패키지 폴더의 .env에 저장하고 bash start-agent.sh로 실행하세요.

    연결 토큰은 지금 한 번만 보여요. 창을 닫으면 다시 볼 수 없어요.

    실물 기기는 USB 디버깅을 켜고 휴대폰에서 PC 인증을 허용하세요.

  3. 3

    연결되면 목록에 자동으로 나타나요

API / MCP 연결

자동화 도구나 AI 에이전트가 내 계정으로 기기를 조작할 수 있게 연결해요. MCP 클라이언트(Claude 등)는 로그인만으로 연결되고, CLI·REST·Android Studio는 토큰을 만들어 설정에 붙여 넣으면 됩니다.

  • 계정당 동시에 1대만 배정
  • 배정은 5분 단위, 연결이 살아 있으면 자동 연장
  • 토큰은 내 계정 권한(일반 사용자)으로만 동작
  • 만료일 최대 90일
  • 토큰은 최대 20개

3연결 확인

클라이언트를 다시 시작한 뒤 list_devices 도구를 호출해 보세요.

정상: {"devices": []} 같은 응답이 와요. 배정 전이라 비어 있는 게 맞아요. 이어서 acquire_device를 호출하면 기기가 배정돼요.

터미널에서 marionette devices를 실행해 보세요.

정상: JSON 목록이 출력돼요. 배정 전에는 []가 나오는 게 맞아요. marionette occupy 뒤에는 배정된 기기 1대가 보여요.

기기 목록 요청(GET /api/devices)을 보내 보세요.

정상: HTTP 200과 {"devices": [...]}. 배정 전에는 목록이 비어 있어요. 401이면 토큰이 틀렸거나 만료·폐기된 거예요.

marionette adb가 켜진 상태에서 다른 터미널에 adb devices를 실행해 보세요.

정상: 127.0.0.1:포트 device 줄이 보이고, Android Studio의 기기 목록에도 나타나요.

4반납과 주의사항

  • 다 쓰면 반드시 반납하세요. 반납하지 않아도 연결이 끊기면 5분 뒤 자동으로 풀려요.
  • 이미 배정된 기기가 있으면 새로 배정할 수 없어요. 먼저 반납하세요.
  • 토큰은 비밀번호와 같아요. 채팅, 저장소, 스크린샷에 올리지 마세요. 유출이 의심되면 아래에서 바로 폐기하세요.

반납 방법 release_device 도구를 호출하세요.
